## Kenapa Netls?

Banyak web downloader di luar sana yang:
- Pake API gratisan yang gampang mati / error
- Penuh iklan & popup
- Minta login / nyuri data
- Tampilannya berantakan di HP

**Netls beda.** Netls gak maksa download ilegal. Netls fokus ke yang paling kepake sehari-hari:
Tempel link -> Deteksi otomatis -> Buka di app resmi -> Simpen jadi koleksi.

Aman, legal, dan gak bakal error karena API pihak ketiga.

## Fitur

| Fitur | Keterangan |
| :--- | :--- |
| **Splash Screen** | `selamat datang di website Netls` + tombol Lanjut ke Halaman |
| **Tampilan iPhone** | Di desktop jadi frame iPhone + Dynamic Island. Di HP jadi fullscreen web app |
| **Dark / Light Mode** | Otomatis kesimpen, gak reset pas refresh |
| **100% SVG Icon** | TikTok, YouTube, Instagram, dll. Tajam di semua layar, tanpa PNG |
| **Auto Detect Link** | Tempel link, langsung ketahuan itu TikTok / YouTube / Instagram |
| **Buka di App Resmi** | Link dibuka di aplikasi aslinya, bukan di download paksa |
| **Copy Link** | 1 klik langsung tersalin |
| **Koleksi Tersimpan** | Link yang disimpan masuk LocalStorage, aman & privat |
| **Paste Otomatis** | Tombol Paste langsung ambil dari clipboard |
| **Responsive** | iPhone, Android, Tablet, Desktop |
| **Tanpa Server** | Cuma 1 file `index.html`, bisa di-host di mana aja |
